## A little about me

I'm a **Computer Science student at FAST NUCES, Lahore** and a full-stack developer who enjoys taking ideas from the frontend all the way to the database and deployment. Most of my work is built with **TypeScript, React, Node.js, NestJS, and PostgreSQL**.

I've worked on everything from a production maintenance platform for a water-treatment client to collaborative finance and developer tools. These projects have taught me how to design secure APIs, model real-world data, and build software that people can actually use.

I'm also interested in the practical side of **AI and machine learning**. Through projects such as CodeMap and API Sentinel, I've explored semantic code search and LLM-assisted diagnostics, and I'm continuing to grow my skills in applied AI/ML.

## Selected work

### [HydroGrid](https://github.com/haziqbilall/HydroGrid) · Water Treatment Operations

A production-deployed maintenance and reporting system built for a real water-treatment client. It manages the operational lifecycle from task assignment through completion reporting and keeps critical documents available to the team.

`React` `NestJS` `TypeScript` `TypeORM` `PostgreSQL` `AWS EC2` `AWS S3`

- Designed workflows for plant maintenance, team coordination, and operational records
- Deployed cloud infrastructure with S3-backed document storage and EC2 delivery

### [SpendSense](https://github.com/haziqbilall/SpendSense) · Collaborative Personal Finance

A multi-user budgeting platform for connected groups to split bills, track shared expenses, and make financial progress visible in one place.

`React` `NestJS` `TypeScript` `PostgreSQL` `Chart.js` `jsPDF`

- Implemented JWT-secured role-based access and collaborative expense tracking
- Added overspending alerts, savings-goal monitoring, dashboards, and PDF exports

### [API Sentinel](https://github.com/irtaza-shahzad/APISentinel) · API Contract Intelligence

A real-time proxy that checks live traffic against OpenAPI specifications, exposing undocumented schema changes and data mismatches as they happen.

`React` `Node.js` `Express` `MongoDB` `OpenAPI` `TypeScript`

- Centralized contract-violation logs in a dashboard built for fast investigation
- Integrated LLM-generated explanations to make validation failures easier to diagnose

### [CodeMap](https://github.com/mamoon-17/CodeMap) · Semantic Codebase Search

An AI-powered platform that indexes large repositories and lets developers query them in natural language for precise code references and contextual explanations.

`React` `Node.js` `Express` `FastAPI` `TypeScript` `TypeORM`

- Built high-performance indexing and retrieval services across TypeScript and Python
- Turned natural-language questions into relevant, context-aware codebase results
