### [SpendSense](https://github.com/haziqbilall/SpendSense) · Collaborative Personal Finance

A multi-user budgeting platform for connected groups to split bills, track shared expenses, and make financial progress visible in one place.

`React` `NestJS` `TypeScript` `PostgreSQL` `Chart.js` `jsPDF`

- Implemented JWT-secured role-based access and collaborative expense tracking

`React` `Node.js` `Express` `MongoDB` `OpenAPI` `TypeScript`

- Centralized contract-violation logs in a dashboard built for fast investigation
- Integrated LLM-generated explanations to make validation failures easier to diagnose

`React` `Node.js` `Express` `FastAPI` `TypeScript` `TypeORM`
